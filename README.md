# freelance-CRM-Showcase – Full-Stack Business Solution

> **Note:** The source code for this repository is strictly private to protect proprietary business logic and client confidentiality. This public repository serves as a technical showcase of the system's architecture, UI/UX, and engineering decisions.

## Project Overview
Architected and deployed a custom Customer Relationship Management (CRM) web application for an international life insurance brokerage. The system modernized their operational workflow, enabling secure lead tracking, pipeline management, and data visualization.

## Tech Stack
* **Frontend:** React.js, JavaScript, CSS
* **Backend & Database:** Google Firebase (NoSQL)
* **Authentication:** Firebase Auth (Secure login and role management)
* **Deployment:** Firebase Hosting

## Key Features & Engineering Highlights
* **Component-Based UI:** Built a highly responsive, state-driven dashboard using React hooks for real-time pipeline health tracking.
* **Secure Cloud Infrastructure:** Configured Firebase to handle real-time data syncing across multiple manager accounts, ensuring high availability and secure data partitioning.
* **Data Portability:** Engineered custom import/export functions allowing the client to seamlessly migrate database records to and from Excel.
